# Tesla Flip 🛹⚡

Tiny mobile-first browser game: Elon Musk rides a miniature Tesla like a skateboard through a parallax city. Tap to kickflip. That's it.

- Play: https://klaymendel-art.github.io/tesla-flip/
- Stack: vanilla HTML5 Canvas, no build step.
- Art generated via OpenRouter (Gemini image models), audio synthesised procedurally with Python/numpy.

See `docs/DESIGN.md` for the design & asset contract.
